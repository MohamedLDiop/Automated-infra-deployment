# infra-project
Automated Linux Server Deployment

## Automated Infrastructure Deployment

## 🚀 Overview
This project demonstrates a simple DevOps workflow to provision and configure a Linux server using Infrastructure as Code and automation tools.

## 🧱 Stack
- Linux (Debian)
- Bash scripting
- Ansible
- Terraform

## ⚙️ Features
- Automated infrastructure provisioning
- Server configuration using Ansible
- Nginx deployment
- Basic monitoring scripts

## 📁 Project Structure
- `scripts/`: Bash scripts for system management
- `ansible/`: Configuration management
- `terraform/`: Infrastructure provisioning
